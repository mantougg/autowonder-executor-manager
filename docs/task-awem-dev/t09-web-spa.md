1. 开工前通读 conventions.md、design.md §9 与 **ui-guidelines.md 全文**——本任务的验收基准就是这份规范。
2. **先规范后代码**（ui-guidelines §7.3）：遇到规范未覆盖的新状态语义/新组件/新令牌，**先更新 ui-guidelines.md 再实现**。
3. 组件只引用 `--awem-*` CSS 变量，不写死色值；状态一律"圆点 + 文字"双编码；本地状态与平台状态**并列展示不合并**。

5. 可访问性：对比度 WCAG AA、全键盘可达、焦点环 2px accent 不得去除。
6. 注释文档中文、标识符英文；状态即改即记：本文件与 [index.md](index.md) 同步 + 双方变更记录各加一行。

### F2 · 鉴权流程

- **开发状态**：✅ 已检查
- **检查状态**：✅ 通过
